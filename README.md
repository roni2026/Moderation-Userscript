# Moderation Userscript (Backup)

A backup export of the Tampermonkey scripts used for moderating listings on the Bikroy admin panel.

This repo holds a raw Tampermonkey export snapshot rather than source-controlled script files. The actual maintained script — the category auto-selector and audit-log notifier — lives in [`tampermonkey_script_bikroy_moderation`](https://github.com/roni2026/tampermonkey_script_bikroy_moderation); this repo exists purely as a point-in-time backup in case a Tampermonkey install needs to be restored.
